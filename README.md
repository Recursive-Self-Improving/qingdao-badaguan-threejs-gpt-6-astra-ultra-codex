# 八大關 · 漫遊

以青島八大關為靈感的 Three.js 互動虛擬景觀。沿著林蔭路、紅瓦別墅與海岸自由探索，感受樹影、海風和日光的變化。

## 本機執行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

開啟終端機顯示的網址。使用 `npm run build` 產生正式版本，使用 `npm run preview` 預覽建置結果。

## 操作

- **W / A / S / D 或方向鍵**：移動。
- **滑鼠拖曳**：旋轉視角。
- **滾輪**：向前或向後移動。
- **Q / E**：降低或提高視點。
- **Shift**：加速移動。
- 畫面上的控制項可切換季節與時段、開關環境音效，以及擷取目前風景。

音效採用瀏覽器 Web Audio API 即時合成海浪、風聲與輕微鳥鳴，點選音效按鈕後才會播放，無須下載音訊檔案。

## 場景與真實地點

八大關的林蔭道路、風格多樣的近代別墅與臨海地貌，是這個場景的主要參考。場景為**藝術化的空間重構，並非依實測資料製作的 1:1 地圖**；道路距離、建築位置及比例經過調整，方便在網頁中漫遊。

地點與歷史背景參考青島日報／青島觀的 [八大關相關報導（2015）](https://www.dailyqd.com/channelzt/2015-08/25/content_270183.htm) 與 [八大關相關報導（2020）](https://www.dailyqd.com/channelzt/2020-09/14/content_522114.htm)。

技術：Vite、Three.js、Lucide、Web Audio API。建議使用支援 WebGL 的現代桌面瀏覽器。
